# ANDstudio - Brand Identity & Design System

## 1. Core Brand Personality
- **Tone**: Professional, modern, warm, reliable, elegant.
- **Visual Voice**: Dark slate theme with refined copper/amber accents reminiscent of professional photo studio lighting.

## 2. Color Palette (Tokens)
- **Canvas (Background)**: `#0f1419` (`slate-950` equivalent, deep slate-black)
- **Surface (Cards/Panels)**: `#1a202c` (`slate-900` equivalent)
- **Surface Elevated**: `#2d3748`
- **Ink (Text Main)**: `#f1f5f9` (`slate-100`)
- **Muted (Text Secondary)**: `#a0aec0` (`slate-400`)
- **Accent Primary**: `#b45309` (Copper / Amber-700)
- **Accent Light**: `#d97706` (Amber-600, glow / interactive states)

## 3. Typography
- **Headings & Body**: `Plus Jakarta Sans` (Clean, geometric, premium sans-serif)
- **Code / Metrics**: `Geist Mono` or monospace equivalent.

## 4. Elevation & Depth
- **Shadow Soft**: `0 1px 2px rgb(0 0 0 / 0.4), 0 8px 24px -8px rgb(0 0 0 / 0.6)`
- **Shadow Lifted**: `0 2px 6px rgb(0 0 0 / 0.45), 0 18px 44px -14px rgb(0 0 0 / 0.75)`
- **Shadow Glow**: `0 0 0 1px rgb(180 83 9 / 0.2), 0 14px 44px -14px rgb(180 83 9 / 0.35)`

## 5. Motion Guidelines
- **Duration**: Fast transitions (0.2s - 0.4s).
- **Easing**: `cubic-bezier(0.22, 1, 0.36, 1)` (smooth deceleration).
- **Page Transitions**: Slide up + fade in on route change.
- **Hover States**: Subtle lift (`y: -4` or `-6`) with soft shadow expansion.
